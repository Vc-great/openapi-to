## Changesets audit and gate design

The tracked policy still has one fixed group containing all ten public runtime
packages. The two config packages and two E2E workspaces remain private.
`.changeset/pre.json` remains tracked with mode `pre`, tag `rc`, the original
initial versions, and the same fourteen consumed Changeset IDs.

`.changeset/new-mice-sit.md` had empty frontmatter and requested no package
bump. It was introduced only to make `changeset status` accept an uncommitted
pre-version tree. It was therefore classified as `WORKAROUND`; after the
versioned tree reached `main`, it became `REDUNDANT`. A temporary clone of the
candidate and the current local tree both ran Changesets 2.28.1 `status`
without this file and returned 0 with no package bumps. The file is removed and
was not replaced by another empty or fabricated bump.

`scripts/verify-changeset-state.mjs` is now the release gate:

- Without `.changeset/pre.json`, it delegates to the official
  `changeset status` command. The existing normal-branch policy is unchanged:
  a valid or absent Changeset follows the repository's current result, while
  an unknown package or damaged frontmatter fails.
- In prerelease mode, it validates the pre-state shape, mode, tag, complete
  initial version map, unique consumed IDs, workspace manifests, exact public
  fixed group, SemVer versions, and the common base/tag/sequence.
- Workspace and public-package names are discovered from
  `pnpm-workspace.yaml`, package manifests, and `.changeset/config.json`; the
  ten names are not hard-coded. Private workspace versions are not required to
  equal the public fixed group.
- A non-empty unconsumed Changeset fails with `NEXT_RC_REQUIRED`. An empty
  Changeset fails with `EMPTY_CHANGESET_NOT_ALLOWED`.
- Success and failure use process exit status, bounded diagnostics, and
  `--json` machine-readable output without local absolute paths.

`release:check` and the Quality package/install-smoke job now invoke

workaround, verifies that `pre.json` exists and is Git-tracked, and checks the
Quality workflow integration.
