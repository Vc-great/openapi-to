# @openapi-to/core

Compiler, diagnostics, artifact, plugin-runtime, inspection, and first-stage diff APIs for `openapi-to`.

The package reads Swagger 2.0 and OpenAPI 3.0/3.1. OpenAPI 3.2 is compatible-read with diagnosed generator gaps, not complete generation support.

Most users should install the aggregate `openapi-to` package. Plugin and tooling authors may import Core directly.

See the repository [capability matrix](../../docs/capability-matrix.md) and [getting-started guide](../../docs/getting-started.md).
